# تجربة المنصة

## الطريقة الأسهل: في السحابة، بدون تثبيت أي شيء

1. افتح هذا الرابط وأنت داخل لحسابك في GitHub:
   **https://codespaces.new/alasillp-star/course?ref=claude/exciting-albattani-r5u25c&quickstart=1**
2. اضغط **Create codespace**.
3. انتظر 5 إلى 8 دقائق في أول مرة. يظهر محرر في المتصفح، والنافذة السفلية (Terminal) تعرض التقدّم: قاعدة البيانات، البيانات التجريبية، ثم بناء المنصة.
4. عند الانتهاء:
   - تُفتح المنصة تلقائيًا في تبويب جديد.
   - إذا لم تُفتح: تبويب **Ports**، ثم السطر **Abdou Academy (3000)**، ثم أيقونة الكرة الأرضية.
   - يظهر في النافذة السفلية كذلك:
     - رابط المنصة `https://…-3000.app.github.dev/ar`
     - رابط رموز الدخول `https://…-8025.app.github.dev`
     - رمز QR تمسحه بالهاتف
5. ادخل بـ `owner@academy.test`، وخذ الرمز من رابط رموز الدخول.

بعدها اتبع السيناريوهات أسفله كما هي. الأوامر مثل `npm run simulate -- order` تكتبها في النافذة السفلية (Terminal).

- المنصة تبقى تعمل في الخلفية حتى لو أغلقت النافذة السفلية أو ضغطت `Ctrl + C`. لإيقافها: `npm run stop`، ولإعادة تشغيلها: `npm run codespace`.
- إذا غاب الرابط عن الشاشة: اكتب `npm run codespace`، فيعيد طباعة الروابط ورمز QR.
- لتحديث المنصة بآخر تعديلاتي: `git pull` ثم `npm run codespace`. يعيد التثبيت والبناء والتشغيل وحده إذا تغيّر شيء.
- يتوقف الـ Codespace وحده بعد 30 دقيقة دون استعمال. لإطالة المدة: افتح https://github.com/settings/codespaces، ثم **Default idle timeout**، وضع حتى 240 دقيقة. التغيير يطبَّق على الـ Codespace الجديد فقط، لا على الموجود.
- للرجوع: افتح نفس الرابط، فتعود لنفس النسخة ببياناتها.
- حساب GitHub المجاني يعطي حوالي 60 ساعة استعمال في الشهر.

> هذه نسخة تجريبية مؤقتة على حسابك في GitHub، وليست موقع البيع النهائي (انظر [GO_LIVE.ar.md](./GO_LIVE.ar.md)). رابط المنصة (المنفذ 3000) يُجعل عامًا ليفتح من الهاتف. رابط رموز الدخول (المنفذ 8025) يبقى خاصًا بك.

# على حاسوبك

## ما تحتاجه (مرة واحدة)

- **Node.js 22** (نسخة LTS) من [nodejs.org](https://nodejs.org)
- **Docker Desktop** من [docker.com](https://www.docker.com/products/docker-desktop/) — شغّله قبل الأوامر
- **Git** من [git-scm.com](https://git-scm.com)
- تطبيق **Google Authenticator** على هاتفك (لحسابات الإدارة)

## التشغيل: أمر واحد

```bash
git clone https://github.com/alasillp-star/course.git
cd course
git checkout claude/exciting-albattani-r5u25c
npm ci
npm run try
```

`npm run try` يقوم بكل شيء وحده:

1. ينشئ ملف الإعدادات `.env.local` بأسرار ورموز جديدة (لا يغيّر أي قيمة موجودة).
2. يشغّل قاعدة البيانات وصندوق البريد التجريبي عبر Docker.
3. يجهّز الجداول ويضيف بيانات تجريبية: دروس، حسابات الفريق، 20 بطاقة، 3 طلبيات.
4. يشغّل المنصة.

- في المرات القادمة: `npm run try` فقط. البيانات تبقى كما هي.
- للبدء من الصفر: `npm run setup -- --reset` ثم `npm run try`.
- لإيقاف المنصة: `Ctrl + C`.

## السيناريو 1: بطاقة في طرد لم يُسلَّم بعد

1. ادخل بـ `owner@academy.test`، ثم افتح «الطلبيات والتوصيل».
2. ستجد:
   - **ORD-1000**: في الطريق، بطاقتها مقفلة.
   - **ORD-1001**: مسلَّمة، بطاقتها تعمل.
   - **ORD-1002**: تنتظر وضع بطاقة.
3. من `.data/demo-data.txt` افتح رابط بطاقة ORD-1000 في نافذة خاصة. تظهر رسالة «بانتظار تأكيد تسليم الطرد».
4. في الإدارة افتح ORD-1000، ثم «تغيير الحالة يدويًا»، واختر «تم التسليم» مع سبب.
5. ارجع لصفحة البطاقة واضغط «إعادة المحاولة»: البطاقة صالحة.
6. اكتب بريدًا، خذ الرمز من http://localhost:8025، وستدخل للدورة.

## السيناريو 2: طلبية من صفحة البيع ثم تحديث من شركة التوصيل

افتح نافذة أوامر ثانية داخل مجلد المشروع:

```bash
npm run simulate -- order
```

يطبع رقم الطلبية ورقم التتبع (مثل `TEST-1234`). بعد ذلك:

1. في الإدارة افتح «الطلبيات والتوصيل»، ثم الطلبية الجديدة.
2. اكتب رقم بطاقة متاحة (من `B0001-00013` إلى `B0001-00020`) واضغط «وضع في الطرد».
3. رابط هذه البطاقة تجده في «بطاقات التفعيل»، ثم الدفعة، ثم «ملف المطبعة (CSV)» (عمود `qr_url`). افتحه: البطاقة مقفلة.
4. جرّب رسالة فشل من شركة التوصيل. البطاقة تبقى مقفلة:
   ```bash
   npm run simulate -- delivery TEST-1234 "Non livré"
   ```
5. ثم رسالة التسليم. البطاقة تُفتح والطلبية تصبح مدفوعة:
   ```bash
   npm run simulate -- delivery TEST-1234
   ```

## السيناريو 3: التجربة من الهاتف

أوقف المنصة (`Ctrl + C`) ثم:

```bash
npm run start:phone
```

- يحضّر المنصة (دقيقة أو دقيقتان) ثم يعرض **رمز QR في الشاشة**. امسحه بهاتفك، ويجب أن يكون على نفس شبكة الواي فاي.
- البطاقات التي تنزّل ملف PDF لها في هذا الوضع تفتح مباشرة بكاميرا الهاتف.

## أشياء أخرى للتجربة

- **المحتوى:** أضف وحدات ودروسًا، رتّبها بالسحب، وارفع فيديو.
- **بطاقات التفعيل:** أنشئ دفعة جديدة ونزّل ملف PDF للطباعة.
- **الأدوار:** ادخل بـ `sales@academy.test` و`support@academy.test` لترى أن الصلاحيات تختلف.

## مشاكل شائعة

| المشكلة                              | الحل                                                                         |
| ------------------------------------ | ---------------------------------------------------------------------------- |
| `PostgreSQL did not answer`          | شغّل Docker Desktop وانتظر حتى يجهز، ثم أعد `npm run try`.                   |
| `Node.js 22.11 or newer is required` | ثبّت آخر نسخة LTS من nodejs.org.                                             |
| المنفذ 3000 مستعمل                   | أغلق البرنامج الآخر الذي يستعمل المنفذ 3000.                                 |
| الهاتف لا يفتح الرابط                | نفس شبكة الواي فاي. واسمح لـ Node.js في جدار الحماية (Windows يسأل أول مرة). |
| الصفحة تعيد التحميل باستمرار         | أوقف المنصة، احذف المجلد `.next/dev`، ثم أعد التشغيل.                        |
| لا يصل رمز الدخول                    | افتح http://localhost:8025. يجب أن يكون Docker يعمل.                         |
